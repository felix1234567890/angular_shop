## Instructions

This project uses Angular 22 and TypeScript 6. Use Node.js 24.15.0 or newer
within the Node.js 24 release line, or Node.js 26.0.0 or newer. CI uses Node.js 24.

1.First clone this repo to use it locally with this command in your terminal:

### `git clone <projectName>`

2.Enter into the project with :

### `cd <projectName>`

3.Install all the dependencies with:

### `npm install`

4.Run the project with:

### `npm start`
